# minimax 主题（short: minimal）

monitor 探针的公开状态页主题。纯静态 SPA，**零依赖、零构建**——整个主题就是 `minimal/dist/index.html` 一个文件。

公开页一屏之内给出四类信息：

| 位置 | 内容 |
| --- | --- |
| 汇总条 | 在线节点数 / 可用率、平均延迟、本月流量、按周期折算的月支出 |
| 节点卡片 | 在线状态与运行时长、**延迟检测块**（每路探测一行：名称 + 近 1 小时曲线 + 当前值 + 丢包率）、CPU / 内存 / 硬盘三条占用、实时上下行速率、**费用**（周期、月均、到期倒计时；没填价格的显示「免费」）、流量统计一行 |
| 详情页 `/node/{id}` | **费用明细**（价格、折合月均、到期倒计时、计费模式、配额与重置日）、**网络延迟检测**（多路探测曲线 + 每路当前/平均/最低/最高/丢包，带平滑 / 削峰 / 只看一路三个视图开关）、资源趋势（CPU / 内存 / 磁盘 / 网络）、基础信息 |
| 其它 | 明暗双色（跟随系统，可手动切换）、`/node/{id}` 可刷新可分享、移动端单列自适应 |

## 主界面结构

```
┌──────────────────┬────────────────────────────────────┐
│   在线节点 6/8   │                                    │
│   平均延迟 94ms  │         世界地图（点阵）            │
│  本月流量 80 GB  │   ● 全在线  ● 部分离线  ● 全离线     │
│   月支出 ¥113    │   6 个地区 · 8 个节点               │
├──────────────────┴────────────────────────────────────┤
│ [搜索节点名、地区、系统…]        [不分组│地区│在线状态│计费周期] │
├───────────────────────────────────────────────────────┤
│ 🇯🇵 日本  3                                             │
│  [卡片]  [卡片]  [卡片]                                 │
│ 🇭🇰 中国香港  1                                         │
│  [卡片]                                                │
└───────────────────────────────────────────────────────┘
```

工具栏一行放下时，搜索框靠左、分组控件**靠右**（`margin-left:auto`）。
窄屏（≤560px）下两者各占一行且**等宽**——搜索框必须去掉 `max-width`，
否则它会停在 360px 而分组控件占满整行，看起来就是「一大一小」。

## 国旗与到期提示

**国旗**由 ISO 3166-1 alpha-2 码现算，不维护映射表：两个区域指示符字符拼起来就是区旗
（`HK` → `🇭🇰`）。出现的位置：卡片与详情页的地区徽标、分组标题、地图弹窗标题。
**Windows 字体不渲染国旗 emoji**，会退化成两个字母，仍可读。

> 地图亮点**不用国旗**——试过，缩到那个尺寸国旗糊成一团反而更差。亮点保持纯色圆点，颜色即在线情况。

**到期提示**做成分级的胶囊徽标，而不是一行小字——这是最容易因为被忽略而真的出事的一条信息。
阈值放到 30 天：只标 7 天的话，半个月后到期在列表里几乎看不见。

| 剩余 | 呈现 |
| --- | --- |
| 已过期 | 红色胶囊「已过期 N 天」 |
| ≤ 7 天 | 橙色胶囊「仅剩 N 天」 |
| 8–30 天 | 浅橙胶囊「N 天后到期」 |
| > 30 天 | 灰色文字「N 天后到期」 |
| 无到期日 | `∞` |

## 世界地图

**数据来源与限制**：hub 的节点只给一个 `country`（ISO 3166-1 alpha-2），**没有经纬度**，所以地图只能按国家定位，同一国家的多个节点合并成一个亮点。

陆地是点阵而非矢量轮廓——由 `dev/gen-map.mjs` 从 Natural Earth 110m（公有领域）生成，
编码成每行 `cols/4` 个十六进制字符（4 格/字符），**文件里只留 5 KB，运行时展开成约 1745 个子路径**。
点阵比填充轮廓更贴合这套极简配色，也小两个数量级。只画纬度 84°N–58°S：南极洲不可能有节点。

| 交互 | 行为 |
| --- | --- |
| 亮点含义 | 一个亮点 = 一个地区（按 `country` 合并） |
| 亮点外观 | 纯色圆点，颜色即在线情况 |
| 颜色 | 全部在线 **绿** / 部分离线 **橙** / 全部离线 **红** |
| 亮点大小 | 半径 6px 起，随节点数小幅增大，最多 10px |
| 悬停 | 原生提示「地区 · N 个节点，离线 M」 |
| 点击亮点 | 在亮点旁弹出该地区的节点列表；**再点同一个亮点关闭**，点别处也关闭 |
| 点击弹窗内的节点 | 进入该节点详情页 |
| 键盘 | Tab 可聚焦亮点，Enter / Space 打开弹窗 |

**状态与边界**

- `country` 为空、或代码不在质心表里 → **不上图**，页脚提示「另有 N 个未标注地区」
- 地区只有 1 个节点时**仍走弹窗**：保持一致，也能看到节点名与状态
- 没有节点 → 只画陆地，页脚显示「0 个地区 · 0 个节点」
- 弹窗定位用亮点自身的 `getBoundingClientRect`，并夹在容器内——地图是等比缩放的 SVG，按 viewBox 坐标算屏幕位置在缩放后会对不上
- 地图每 2 秒随数据重画一次：陆地点阵**只在首次渲染**，之后只替换亮点图层；弹窗内容有指纹比对，**没变化就只重新定位、不重建 DOM**，否则用户正要点的按钮会被换掉
- 国旗用两个区域指示符拼出，不维护映射表。已知限制：**Windows 的字体不渲染国旗 emoji**，会退化成两个字母（如 `JP`），仍可读

## 搜索与分组

**搜索**匹配范围：节点名、地区中文名、国家码、系统名、虚拟化、架构、CPU 型号。
空格分词，**全部命中**才算匹配（AND），大小写不敏感。无结果时给出空状态与「清空搜索」。

**分组**四种模式：不分组 / 地区 / 在线状态 / 计费周期。

- 组头显示名称与数量，**空组不出现**
- 组间按数量降序，数量相同按名称排序
- 缺失值归到「未标注地区」「未设置计费周期」，而不是把节点丢掉

## 模块联动

| 模块 | 受什么影响 | 影响什么 |
| --- | --- | --- |
| 汇总磁贴 | 只跟节点数据 | —— |
| 世界地图 | 搜索关键词 | 点击亮点 → 弹窗 → 详情页 |
| 节点网格 | 搜索 + 分组 | 点击卡片 → 详情页 |
| 计数文案 | 搜索 + 分组 | —— |

两条关键约定：

1. **汇总磁贴始终是机队总览，不随搜索变化**。搜索只作用于地图和网格，这样磁贴上的「在线 6/8」不会因为搜了个关键词就变成另一种含义。地图在筛选生效时右上角显示「已按当前筛选」。
2. **输入时只重绘网格与地图，工具栏不重建**。否则每 2 秒一次的 WebSocket 推送会把搜索框的焦点和光标吃掉，打到一半的字会丢。

## 延迟面板的三个视图开关

都在详情页「网络延迟检测」面板的标题右侧，可叠加使用。

| 开关 | 做什么 | 什么时候用 |
| --- | --- | --- |
| **平滑** | 对整条曲线做居中滑动平均（窗口 5） | 抖动太密看不清趋势时 |
| **削峰** | Hampel 滤波：只把偏离窗口中位数超过 3 倍稳健标准差的点换成该中位数，**其余点原样通过** | 偶发尖刺干扰读数时。它只动离群点，不会把整条曲线摊平 |
| **只看一路** | 点图例或下表任意一路，**图中**只留这一路；再点一次恢复全部。下表始终列全，被隔离的那行高亮 | 某一路慢得多时。隔离后纵轴会按这一路重新缩放，否则其余几路会被压成贴着底部的平线，什么都看不出来 |

三者可以叠加：先削峰去离群点，再平滑压抖动，最后隔离出要看的那一路。

曲线一律是**实线**——色板本身就够区分，再叠虚线只是噪声。隔离单路时线会加粗，并在折线下填一层**同色半透明面积**，让这一路的起伏更容易读。

**超时的点会被跳过，但线不断开**。留断口会把整条走势切成碎片，反而看不出趋势；丢包信息本来就由下表与卡片上的丢包率承载，不必再让曲线去表达。

两个刻意的取舍：

- **超时是断点，不是读数**。削峰和平滑都跳过 `null`，也不把它算进邻域——否则丢包在曲线上会被平均填平，看不见了。
- **表格统计始终基于原始样本**。曲线是处理后的结果，但下表的最低 / 最高 / 平均仍是真值；否则「最高」会被削峰削掉，读数就没有依据了。面板下方会写明当前生效的处理。

轴标签遇到半步刻度会如实印成 `-7.5` 之类而不做四舍五入——阶梯步长含 1.5 / 2.5 / 7.5，四舍五入会印出一个和网格线对不上的数。

## 卡片布局

卡片的纵向顺序，以及为什么这么排：

```
┌──────────────────────────────────────────────┐
│ ● 节点名  [地区]                  在线 14 天 │   ← 在线徽标带淡绿底
│ 系统 · 虚拟化 · 架构             160 天后到期 │
├──────────────────────────────────────────────┤
│ 延迟检测                          近 1 小时 │   ← 主视觉，每路一行
│  ● 电信 163    ╱╲╱╲╱╲           39 ms  0%   │   ← 蓝
│  ● 联通 4837   ╲╱╲╱╲╱           31 ms  2%   │   ← 橙
│  ● 移动 CMIN2  ╱╲╱╲╱╲           45 ms  0%   │   ← 紫
├──────────────────────────────────────────────┤
│ CPU 2 核        内存          硬盘           │   ← 三条占用，各有一色
│ 0.37 0.00 0.00  0.66/2.00 GB  11.6/40.0 GB  │
│ ▓░░░░░░         ▓▓░░░░░       ▓▓▓░░░░       │
├──────────────────────────────────────────────┤
│ ↓ 4.8 MB/s  ↑ 1.8 MB/s       月付 ¥68.00/月 │
│ ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │   ← 配额进度，2px，青色
│ 流量 3.32 / 500.00 GB · 0.7%  累计 ↓146 ↑43.5│   ← 压成一行
└──────────────────────────────────────────────┘
```

**三路探测共用同一个纵轴范围**。各自归一化的话，37 ms 和 110 ms 会被画成一模一样的形状——而三网并排展示的全部意义就是看出哪一路更差。每路配一个与曲线同色的圆点做识别，名称保持中性：三行彩色文字反而不好认。

**丢包率一律显示，0% 也占位**。只给有丢包的行加标记的话，那一行会多出一段宽度，三行的时延数值就参差不齐了。时延与丢包各自固定宽度右对齐，0% 用浅灰、有丢包才转红。

卡片上最多列 3 路探测（`CARD_PROBES`），多出来的在详情页看。列表要的是「通不通、多快」，不是完整的多路曲线。

列表页取延迟时用 `points=60`：迷你曲线只有一百来像素宽，按设备像素宽度去要会让每个节点都发一次大响应。

卡片内容密度较高（三路延迟 + 三条占用 + 速率费用流量），所以网格最多排三列，断点在 780 / 1140 px，以保证占用条的数值不被截断。

## 配色

图表色板 `--c1`…`--c5` 按可辨识度排序，前三个是蓝 / 橙 / 紫——深浅两种主题下都能一眼分开，绿和红留给「在线」与「告警」的语义，所以探测色不占用它们。色板在 `:root` 与 `html.dark` 各定义一份，深色下整体提亮。

| 元素 | 用色 |
| --- | --- |
| 汇总磁贴 | 顶部 3px 色条 + 同色圆点：在线绿 / 延迟蓝 / 流量青 / 支出紫 |
| 在线徽标 | 淡绿底 + 绿字；待上报为琥珀色 |
| 探测圆点与曲线 | `--c1` 蓝、`--c2` 橙、`--c3` 紫，依次往后 |
| 占用条 | CPU 蓝、内存绿、硬盘紫；≥75% 转琥珀、≥90% 转红 |
| 配额进度条 | 青色；≥75% 琥珀、≥90% 红 |
| 详情页面板标题 | 左侧 3px 色条，按面板区分 |

底色本身保持克制（浅色 `#f4f6f9`，深色 `#0a0b0e`），色彩都落在数据本身上。

## 安装

**方式一**：把 `theme.tar.gz` 拖进后台「主题」页。

**方式二**：把 `minimal/` 目录整个放进 hub 的 `--themes` 位置（一键脚本装出来的是 `/opt/monitor/data/themes/`），然后在「主题」页选中，无需重启。

选中的主题缺失或损坏时，hub 会自动回落到内置默认主题。

> **归档布局**：`theme.tar.gz` 的**根目录就是主题目录的内容**——`theme.json`、`preview.png`、`dist/` 平铺在归档根上，**没有外层目录**。hub 会把它解到 `<themes-dir>/<short>/`。多套一层目录会导致安装后的主题缺 `theme.json`。`dev/package.mjs` 会校验这一点。

## 本地预览

没有真实 hub 也能看效果。`dev/mock-server.mjs` 用纯 Node（无第三方依赖）模拟了 hub 的全部四个同源接口，含手写 WebSocket 握手与文本帧：

```bash
node dev/mock-server.mjs --port 9911     # 打开 http://127.0.0.1:9911/
```

参数：

| 参数 | 用途 |
| --- | --- |
| `--freeze` | WS 只推一次就静默，便于无头浏览器截图时页面进入空闲 |
| `--nows` | 拒绝 WebSocket 升级，强制主题走 5 秒轮询的降级路径 |
| `--closed` | 头 1.5 秒假装公开页可用，之后 `/api/nodes` 一律 401、`/api/me` 改口 `public_page: false`，用来验证运行期关闭时主题会重查 `/me` 并跳转后台 |
| `?dark=1` | 以深色模式启动（无头浏览器改不了 `prefers-color-scheme`） |
| `?click=smooth,only2` | 渲染完成后依次点击，用来在无头环境里截取交互态（`smooth` / `despike` / `only1..3` / `range6`，也可直接写选择器） |
| `?q=日本` / `?group=region` / `?popup=JP` | 直接把主界面的状态摆好，用来在无头环境里截取筛选、分组、地图弹窗的样子 |
| `?probe=geo` | 把关键元素的 `getBoundingClientRect` 与 `computed display` 写进 `document.title`。判断「有没有对齐」必须量，不能靠看截图猜 |

对着真实 hub 开发时，起一个 hub 实例即可（主题侧无需代理配置，因为本主题不跑 Vite）：

```bash
monitor-hub --listen 127.0.0.1:9911 --db /tmp/monitor.db --site http://127.0.0.1:9911
```

## 开发与校验

```bash
node dev/test.mjs        # 纯函数自测，失败退出码非零
node dev/package.mjs     # 校验 theme.json / 目录名 / 体积上限，然后打包
```

`dev/test.mjs` 的做法是给主题脚本喂一个最小 DOM 桩后整体求值，因此不需要测试框架，也不需要把函数拆成模块——脚本顶层声明在 vm 里会挂到全局对象上，直接取来调用即可。覆盖：数字格式化与时长换算的边界（0、负数、小数、NaN、缺字段）、费用折算与多币种分组、延迟样本分组与迷你曲线、削峰 / 平滑 / 单路隔离的曲线处理、地区合并与配色、搜索匹配与分组、国旗拼装与到期分级、坏数据降级、地区码与坐标轴取整。

## 接口契约

只用这四个同源接口，全部按「这个 key 可能不存在」处理：

| 接口 | 用途 |
| --- | --- |
| `GET /api/me` | 站点名、登录状态、公开页开关 |
| `GET /api/nodes` | 节点列表、实时指标、累计流量 |
| `GET /api/nodes/{id}/metrics` | 历史指标与延迟记录 |
| `GET /api/ws` | 每 2 秒推送一次节点快照 |

`metrics` 的三个查询参数都用到：

- `hours=N` 窗口宽度，延迟取 1/6/24 小时，资源取 1/6/24 小时与 7 天
- `points=W` 按设备像素宽度上报，只让 hub 抽得更稀
- `series=metrics|ping` 分开取，省掉不画的那一半

丢包率取自响应的 `loss`（整个窗口，按探测 id 给百分比），**不是**拿样本行里的 `loss` 自己平均——那是所在桶的百分比，除数已经丢了。探测曲线的名字取自响应的 `probes`，因此画延迟图不需要第二个请求，也不需要管理员身份。

## 三种状态的降级

| 状态 | 表现 |
| --- | --- |
| 离线（`metrics: null`） | 状态点变灰，显示「离线 x 小时」，占用条留空但保留机器规格 |
| 已连接未上报（`online: true` + `metrics: null`） | 显示「已连接 · 待上报」与「正在等待第一次上报」，区别于从未接入的节点 |
| 坏数据（字段缺失或类型不对） | 入口处做一次完整指标校验，不合格只把该节点的 `metrics` 置空并显示「不可用」，不让一个节点的坏数据把整页白屏 |

另外，公开页在标签页打开期间被关闭时，主题会重查一次 `/api/me`；确认已关闭且无人登录就把访客送去 `/admin/`，而不是留在一个不再更新的列表上。

## 与默认主题的差异

- 不依赖 React / Vite / shadcn，单文件交付，没有构建期变量，克隆下来直接改
- 列表页就带延迟检测，且**每路探测一行**（三网就是三行）并共用纵轴、一色一路，默认主题只在详情页画延迟
- 详情页延迟面板可平滑 / 削峰 / 只看一路，并支持明暗双色与卡片层次（阴影、悬停抬起）
- 汇总条直接给「平均延迟」和「月支出」；费用明细在详情页单独成块
- 流量统计在卡片上压成一行，不再占一个占用条
- 多币种不合并：hub 不提供汇率，把 USD 和 CNY 相加会得到一个不存在的数，因此分币种并列显示
- 国家码映射为中文名（含中国香港 / 中国澳门 / 中国台湾的正确表述），未收录的代码原样显示
